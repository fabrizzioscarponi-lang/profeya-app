# profeya-app
**ProfeYa**
**Descripción del proyecto**

ProfeYa es una aplicación web orientada a conectar profesores con estudiantes que necesitan apoyo académico.

La plataforma busca facilitar la búsqueda de docentes, mejorar la comunicación entre alumnos y profesores, y simplificar el acceso a clases particulares.

**Problema que intenta resolver**

Muchos estudiantes tienen dificultades para encontrar profesores particulares de manera rápida y confiable.
ProfeYa centraliza esta búsqueda en una única plataforma sencilla y accesible.

**Usuarios principales**

Estudiantes que buscan apoyo académico
Profesores que desean ofrecer clases particulares

**Funcionalidades actuales**

Landing principal
Registro de profesores
Inicio de sesión de profesores
